Build a graphic one layer at a time

ggplot2 is the R package for data visualization. You describe what the data means visually, and it draws the chart. Step through the example below to see how a plot grows.

    
    
    
    
    
  
    

    


    
  
    The idea: a grammar of graphics
    
  
    Instead of picking a chart type from a menu, you combine independent parts. Change one part and the rest stays put. That is why a scatter plot becomes a set of small multiples with one added line.
    
  
    
    
    Data
    A data frame, where each row is an observation and each column is a variable. Passed to ggplot().
    
    
    Aesthetics
    The mapping from variables to visual properties such as position, colour, size and shape. Written inside aes().
    
    
    Geoms
    The shapes that show the data: points, lines, bars, boxes. Each is a layer added with +.
    
    
    Scales
    Control how values become visuals: axis limits, colour palettes, log transforms. Functions start with scale_.
    
    
    Facets
    Split one plot into panels by a variable with facet_wrap() or facet_grid().
    
    
    Themes
    Everything that is not data: fonts, grid lines, backgrounds. Try theme_minimal() or theme_bw().
    
  
    

    


    
  
    Your first plot
    
  
    ggplot2 is part of the tidyverse. Install it once, load it each session, and use one of the built-in datasets to try it.
    
  
    
    
    
      
    Install and load
    

    # install once
install.packages("ggplot2")

# load every session
library(ggplot2)
    
    
    
    
    
      
    Plot fuel economy
    

    ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point()

# save the last plot
ggsave("mpg.png", width = 6, height = 4)
    
    
    
  
    
  
    Read the code as a sentence: take the mpg data, map engine size to x and highway mileage to y, then draw points. The + at the end of a line tells R that another layer follows.
    

    


    
  
    Patterns you will reuse
    
  
    
    
    
      
    Split into panels
    

    ggplot(mpg, aes(displ, hwy)) +
  geom_point() +
  facet_wrap(~ class)
    
    
    
    
    
      
    Compare distributions
    

    ggplot(mpg, aes(x = class, y = hwy)) +
  geom_boxplot() +
  coord_flip()
    
    
    
    
    
      
    Count categories
    

    ggplot(mpg, aes(x = class, fill = drv)) +
  geom_bar(position = "dodge")
    
    
    
    
    
      
    Set colours yourself
    

    ggplot(mpg, aes(displ, hwy, colour = drv)) +
  geom_point() +
  scale_colour_manual(
    values = c("4" = "#1B9E77",
               "f" = "#D95F02",
               "r" = "#7570B3"))
    
    
    
  
    

    


    
  
    Choosing a geom
    
  
    Start from the question you want the chart to answer.
    
  
    
    
    You want to showTryNotes
    
    
      
    Two numeric variablesgeom_point()Add geom_smooth() for a trend.
    
      
    Change over timegeom_line()Use group or colour for several series.
    
      
    One numeric variablegeom_histogram(), geom_density()Set binwidth in histograms.
    
      
    Numbers across categoriesgeom_boxplot(), geom_violin()Boxes summarise, violins show shape.
    
      
    Counts of categoriesgeom_bar()Use geom_col() when you already have the totals.
    
      
    Values on a gridgeom_tile()Map a variable to fill.
